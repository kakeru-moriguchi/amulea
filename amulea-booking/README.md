# Amulea 予約システム

Amulea（アミュレア）の予約専用Webアプリです。
公式LINEのリッチメニュー「予約」から直接開く運用を想定しています。

既存のホームページ（<https://amulea.vercel.app/>）とは
**完全に別のプロジェクト**として作られています。

---

## できること

### お客様

- 空いている日時だけを見て予約する（埋まっている時間は表示されません）
- 予約内容の確認
- 予約日時の変更
- 予約のキャンセル
- 予約完了・変更・キャンセルの LINE 通知を受け取る

### 管理者

- 本日の予約数・次の予約・売上予定をひと目で確認
- 予約の一覧・詳細（電話番号・ご要望まで確認できます）
- 電話や口頭で受けた予約の手動登録
- 予約の変更・キャンセル
- 日別カレンダー（Googleカレンダーの私用予定も表示）
- 営業時間・準備時間・休業日・受付停止・LINE通知の設定
- メニューと料金の編集

## いますぐ動かしてみる

**Google も LINE も設定せずに、全機能を試せます。**

```bash
cd amulea-booking
npm install
npm run dev
```

ブラウザで開きます。

| URL | 内容 |
| --- | --- |
| <http://localhost:3000> | お客様の予約画面 |
| <http://localhost:3000/admin> | 管理画面 |

管理画面のログイン情報（開発中のみ）:

```
ID       : admin
パスワード : amulea-dev
```

> 💡 この状態（`MOCK_MODE=true`）では、予約データはサーバーのメモリ上にあります。
> サーバーを再起動すると消えます。Google・LINE への通信も一切行いません。
> **デザインや操作感の確認は、この状態で自由に試してください。**

## 本番で使うまでの流れ

準備は4段階です。1つずつ進めれば大丈夫です。

```
STEP 1  Vercel に公開する          （15分）
STEP 2  管理者パスワードを設定する  （5分）
STEP 3  Google 連携を設定する      （20〜30分）→ docs/SETUP-GOOGLE.md
STEP 4  LINE 連携を設定する        （30〜40分）→ docs/SETUP-LINE.md
```

---

## STEP 1　Vercel に公開する

1. <https://vercel.com/> にログインします
   （GitHub アカウントでログインするのが簡単です）。
2. **Add New → Project** をクリックします。
3. このリポジトリ（`amulea`）を選びます。
4. **重要**: **Root Directory** の **Edit** をクリックし、
   `amulea-booking` を選びます。

   > ⚠️ ここを設定しないと、既存のホームページのほうが
   > 公開されてしまいます。必ず変更してください。

5. **Deploy** をクリックします。
6. 数分で `https://amulea-booking-xxxx.vercel.app` のような
   URLが発行されます。

### 独自ドメインを使う場合

`booking.amulea.jp` を使いたい場合は、
**Settings → Domains** から追加してください。

---

## STEP 2　管理者パスワードを設定する

### ① 必要な値を作る

パソコンのターミナルで、このフォルダに移動して実行します。

```bash
node scripts/generate-secret.mjs
node scripts/hash-password.mjs "ここに決めたパスワード"
```

それぞれ1行ずつ表示されるので、メモしておきます。

> 🔐 パスワードは10文字以上で、英字の大小・数字・記号を混ぜてください。
> **元のパスワードはどこにも保存されません。忘れないようご注意ください。**

### ② Vercel に登録する

1. Vercel のプロジェクトを開きます。
2. **Settings → Environment Variables** を開きます。
3. 次の値を1つずつ登録します（Key と Value に分けて入力します）。

   | Key | Value |
   | --- | --- |
   | `MOCK_MODE` | `false` |
   | `APP_URL` | 発行されたURL（例: `https://booking.amulea.jp`） |
   | `SESSION_SECRET` | ①で作った値 |
   | `ADMIN_ID` | お好きなログインID |
   | `ADMIN_PASSWORD_HASH` | ①で作った `scrypt$...` の値 |

4. **Save** をクリックします。
5. **Deployments** タブから最新のデプロイの **⋯ → Redeploy** を実行します。

   > ⚠️ 環境変数は、登録しただけでは反映されません。
   > **必ず Redeploy してください。**

### ③ 確認

`https://（あなたのURL）/admin` を開き、
設定したIDとパスワードでログインできれば成功です。

---

## STEP 3　Google 連携

👉 **[docs/SETUP-GOOGLE.md](docs/SETUP-GOOGLE.md)** に、
画面の操作を1つずつ書いています。

これを設定すると、次のことができるようになります。

- 予約が Google カレンダーに自動登録される
- **カレンダーに私用の予定を入れると、その時間は自動で予約不可になる**
- **終日の予定を入れると、その日は丸ごと休業になる**
- 予約データが Google スプレッドシートに保存される

---

## STEP 4　LINE 連携

👉 **[docs/SETUP-LINE.md](docs/SETUP-LINE.md)** に、
画面の操作を1つずつ書いています。

これを設定すると、次のことができるようになります。

- 公式LINEのリッチメニューから予約ページが開く
- お客様がログイン操作なしで予約できる
- 予約完了・変更・キャンセルの通知が LINE に届く
- 新規予約が入ったら管理者の LINE に通知が届く

## 日々の運用

### 休業日を設定する

**方法1: Google カレンダーを使う（かんたん）**

カレンダーに**終日**の予定を入れるだけです。
タイトルは「休業」など分かりやすいものにしてください。

**方法2: 管理画面を使う**

**設定 → 臨時休業日** から日付を追加します。
お客様に表示する理由も設定できます。

### 一部の時間だけ予約を止める

- **Google カレンダー**: その時間に予定を入れる（例: 15:00-17:00「私用」）
- **管理画面**: **設定 → 予約受付を止める時間帯** から追加

### 予約をすべて止める

**設定 → 予約の受付** のスイッチをオフにします。
お客様の画面には、設定した文章が表示されます。

### 料金・メニューを変える

**設定 → メニューと料金** から変更できます。

> 💡 変更しても、**過去の予約の金額は変わりません**。
> 予約時点の内容が予約データに記録されているためです。

### 施術の前後に準備時間を入れる

**設定 → 予約枠と準備時間** から、
0 / 15 / 30 / 45 / 60 分を選べます。

例: 90分コース + 片付け30分 → 合計120分を1つの枠として押さえます。

---

## 営業時間の考え方

初期設定は次のとおりです（管理画面から変更できます）。

| | 営業時間 | 最終受付 |
| --- | --- | --- |
| 月〜金 | 13:00 - 23:00 | 20:00 |
| 土・日・**祝** | 12:00 - 23:00 | 20:00 |

**日本の祝日は自動で判定されます**（振替休日・国民の休日を含みます）。
設定は不要です。

### 「最終受付20:00」の意味

**「20時までに施術が終わる」ではなく「20時までに施術を始める」**という仕様です。

- 20:00 開始の120分コース → 22:00 終了 → **予約できます**
- 22:00 開始の120分コース → 24:00 終了 → 営業時間外のため**予約できません**

## よくある質問

**Q. 既存のホームページに影響はありますか？**
A. ありません。完全に別のプロジェクトで、別のURLで動きます。

**Q. お客様はアカウント登録が必要ですか？**
A. 不要です。公式LINEから開くだけで本人確認が完了します。

**Q. 他のお客様の予約は見えてしまいませんか？**
A. 見えません。URLの予約IDを書き換えても、
サーバー側で本人確認を行うため取得できません。
詳しくは [docs/SECURITY.md](docs/SECURITY.md) をご覧ください。

**Q. 同時に2人が同じ時間を予約したらどうなりますか？**
A. 先に確定した1人だけが成立します。
もう1人には「先ほど他のお客様の予約が入りました」と表示され、
時間の選び直しに戻ります。
仕組みは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) の
「8. 予約競合防止方法」をご覧ください。

**Q. 予約データはどこにありますか？**
A. Google スプレッドシートです。
いつでもご自身で開いて確認・保存できます。

**Q. キャンセルされたデータは消えますか？**
A. 消えません。「キャンセル済み」という状態に変わり、履歴として残ります。

| ファイル | 内容 |

### 主要な処理の場所

| やりたいこと | 見るファイル |
| --- | --- |
| 空き時間の計算ルールを変える | `lib/domain/availability.ts` |
| 予約・変更・キャンセルの流れを変える | `lib/domain/booking.ts` |
| LINE の文面を変える | `lib/line/messages.ts` |
| メニューの初期値を変える | `lib/domain/defaults.ts` |
| 色や書体を変える | `app/globals.css` |
| 保存先を変える（DB移行など） | `lib/store/types.ts` を実装したクラスを追加 |

### 技術構成

Next.js 16（App Router）/ TypeScript / Tailwind CSS v4

**外部ライブラリを追加していません。**
Google API も LINE API も、Node 標準の `crypto` と `fetch` だけで
実装しています（依存を減らし、脆弱性の影響を受けにくくするため）。
