# 写真の置き場所

このフォルダに画像ファイルを置いてください。

例）`azusa.jpg` を置いた場合、`data/therapist.ts` の
`photo.src` を次のように書き換えます。

```ts
photo: {
  src: "/images/azusa.jpg",   // ← "" から書き換える
  alt: "セラピスト あずさ",
},
```

`src` が空文字 `""` のあいだは、ブランドカラーの
プレースホルダーが表示されます。

## 推奨サイズ

| 用途 | 推奨サイズ | 縦横比 |
| --- | --- | --- |
| メインビジュアル（トップページ） | 幅 2000px 以上 | 横長 |
| 各ページのヘッダー背景 | 幅 2000px 以上 | 横長 |
| セラピスト写真 | 幅 1200px 程度 | 3:4（縦長） |
| メニュー写真 | 幅 1200px 程度 | 4:5（縦長） |

ファイル形式は `.jpg` / `.png` / `.webp` が使用できます。
表示サイズの最適化は Next.js が自動で行います。
